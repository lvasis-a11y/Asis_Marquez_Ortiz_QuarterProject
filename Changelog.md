**CHANGELOG**

This file lists all the updates made to our Simple Finance Tracker project.

**Version v1.1.0 – October 23, 2026**

- Added a feature that allows users to omit expenses that have already been paid.
- Updated budget calculations to subtract paid expenses from the remaining budget.
- Improved expense calculations to exclude paid expenses from the total.
- Added warnings when users attempt to pay for an expense that exceeds their available budget.
- Added instructions on how to run the program.
- Included an example output to demonstrate how the program works.
- Updated the project description and features to reflect the completed program.

**Version v1.0.0 – September 14, 2026**

- First version of the project.
- Planned features include:
  - Creating and removing expense categories.
  - Adding expenses and their corresponding costs.
  - Entering a budget.
  - Calculating the total expenses in each category.
  - Displaying all categories and expenses.
  - Handling invalid inputs, such as negative numbers and letters instead of numbers.
