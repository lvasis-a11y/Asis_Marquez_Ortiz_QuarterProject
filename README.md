# Project Title Simple Finance Tracker 

## Project Description 
This simple program allows people who struggle with managing their finances to keep track of their expenses, budget, and etc. 

## Features
- Allows the user to group each of their expenses into certain categories and remove old categories.
- For each category, the user can list each expense and their total cost.
- The user can also enter their budget.
- Calculates the combined total cost in each category.
- If the user already paid for a certain expense, the total cost of that expense will be subtracted from their total budget and that expense will be omitted from that category.
- Handles invalid inputs and warns when the user tries to pay for an expense that does not fit their budget. (Ex. Negative numbers, letters instead of actual numbers, etc.)
